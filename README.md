# Read Aloud 中英朗读

Reads Chinese and English text aloud, with numbers, years, currency, percents, dates and
times spoken correctly (useful for financial articles). Word highlighting, click-to-resume,
speed 0.5×–3×, voice preview and a floating pop-out window.

## Use as a web page
Open `index.html` in Chrome, Edge or Safari. No server needed.

## Use as a Chrome extension
1. Open `chrome://extensions` and switch on **Developer mode**.
2. Click **Load unpacked** and choose this folder.
3. Pin the extension. Clicking its icon opens the reader in the side panel.
4. Select text on any web page, right-click → **用 Read Aloud 朗读选中文字**.

Requires Chrome 116+. After changing any file, press the reload icon on the extension card.

## Voices
Chrome's online "Google 普通话" voice sounds the most natural but needs internet and does not
report word positions (the word highlight is then estimated). Local system voices work offline.
